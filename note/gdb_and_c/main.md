**heap**
---

_a chunk of memory that allocated by user and do not free itself, you have to free it manually or GC, from the start address(low) to the end address(high)_

**Stack**
---

_the other memory usage besides heap, in other word, The stack is a temporary memory area occupied during the execution of functions. It has a rule call last in first out, because the last push frame is execute first, so it release first, in that way, at the end of the whole function execution, the whole stack get freed. Due to the characteristics of the stack, memory is allocated from top to bottom_
